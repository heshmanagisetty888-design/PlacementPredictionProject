Help & Documentation

Find answers to common questions and learn how to use the dashboard

Welcome to the Student Performance Dashboard!
  1. Upload Data: Go to "Dataset Loading" to upload your student data in CSV or Excel format.
  2. Preprocess Data: Visit "Preprocessing" to clean and prepare your dataset.
  3. Train Model: Go to "Predict" to train machine learning models.
  4. Make Predictions: Input student data to get performance predictions.
  5. View Analytics: Explore data insights in "Analytics".

Uploading Your Dataset
  • Supported Formats: CSV, Excel (.xlsx, .xls)
  • File Size Limit: 100MB
  • Requirements: File must contain proper headers in the first row
  • Preview: After upload, you'll see a preview of your data with basic statistics
Make sure your dataset is clean and properly formatted before uploading.

Available Preprocessing Operations
  • Missing Values Handling: Fill or remove missing values using mean, median, or mode
  • Encoding: Convert categorical variables to numerical format
  • Feature Scaling: Standardize or normalize numerical features
  • Outlier Detection: Identify outliers using IQR method
  • Remove Duplicates: Remove duplicate rows from your dataset

Training a Model
  • Target Column: Select the column you want to predict
  • Model Type: Choose between Regression (numeric) or Classification (categorical)
  • Test Size: Percentage of data to use for testing (default: 20%)
Making Predictions
  • Enter values for all required features
  • Click "Predict" to get the result
  • The prediction will appear in the results panel

Available Analytics
  • Correlation Heatmap: Visualize relationships between numerical features
  • Distribution Plots: Understand the distribution of your data
  • Summary Statistics: View statistical summaries of your dataset
Click "Load Analytics" to generate visualizations from your current dataset.

Common Questions
Q: What file formats are supported?

A: CSV and Excel (.xlsx, .xls) files are supported.

Q: How large can my dataset be?

A: Maximum file size is 100MB.

Q: What happens to my data?

A: Your data is processed locally and not stored permanently. Data is cleared when you restart the application.

Q: Can I save my trained model?

A: Yes, trained models are saved in the 'models' folder and can be reloaded.

Q: How do I get support?

A: Check the documentation or contact your system administrator.
